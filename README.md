A lightweight, modern Fly & Noclip GUI script for Roblox.

## 🚀 Usage

Copy and paste the following script into your executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/M4TE0SCRIPTS/FlyScript/refs/heads/main/FlyGUI"))()
```

## ✨ Features
- **Fly:** Smooth directional flight with adjustable speed.
- **Noclip:** Walk through walls and obstacles seamlessly.
- **Modern UI:** Clean, sleek, and draggable interface.
